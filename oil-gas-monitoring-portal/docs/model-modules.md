# Statistical, ML, CV, NLP and transformer modules

The 18 downloaded datasets each have a registered module, explicit data adapter, experimental run report and model artifacts. This adds offline analytical baselines, not site-approved operational models. No trained artifact is connected to emergency controls or silently emits PPE violation records.

## Methods and boundaries

| Family | Implemented method | Evaluation / limitation |
|---|---|---|
| Statistical | Per-feature distributions/missingness; training-median and MAD deviation model | Reports held-out rows beyond three robust deviations; constant/MAD-zero features excluded from that rule; deviations are not verified failures |
| Supervised ML | Class-balanced random forest for pipeline Condition, equipment Failure Type, facies, oil spill target and gas class | Balanced accuracy, macro F1, confusion matrix and majority baseline; group split for wells and gas batches |
| Unsupervised ML | Isolation forest for datasets without supported labels | Reports held-out anomaly flags; no fabricated ground-truth accuracy |
| CV | Annotation inventory and a small CNN for image-level NO-Hardhat presence | Original train/test folders; 160 training and 80 test images; two epochs. This is a bounded smoke baseline, not a bounding-box detector or compliance classifier |
| NLP | TF-IDF retrieval over approved local project/source/scenario documentation and module cards | Returns actual source snippets and character offsets; abstains when there is no lexical match; no generated safety instructions |
| Transformer, tabular | From-scratch feature-token transformer trained to reconstruct standardized numeric features | Three epochs on up to 1,000 training and 300 test rows; held-out reconstruction MSE and training-mean baseline. Not a temporal forecast or pretrained language model |
| Transformer, images | Small from-scratch patch transformer for the same PPE image-level task | Balanced accuracy/confusion matrix; same held-out image subset. Not a pretrained ViT or trained object detector |

CV is explicitly not applicable to modules with only tabular inputs. NLP provides a shared documented knowledge workflow rather than pretending numeric data is text. Generic transformer reconstruction gives an experimental baseline; good reconstruction error does not prove useful anomaly detection, risk classification or forecast accuracy.

## Dataset and split handling

- LAS well-log measurements are parsed as data; -999.25 NULL values become missing. Deviation files are retained raw and excluded from this baseline.
- Gas drift sparse features are parsed into 128 numeric columns; batches are held out as groups.
- Facies wells are held out as groups; nearby depths from the same well do not cross the split.
- Drilling title, units and section rows are removed using numeric depth.
- Volve uses the daily sheet; monthly totals are not pooled with daily rows.
- Larger tables use at most 5,000 evenly spaced rows; this is a compute-bounded baseline, not full-data training.
- Environmental, price, demand and Volve rows are ordered before holdout. Multiseries pooling remains exploratory and requires per-device/well/symbol/region models before forecasting.
- Medians/scalers fit training data only. Numeric identifiers and target aliases are excluded. Categorical encodings, unit validation and target leakage audits remain release work.
- Pipeline condition features may describe contemporaneous corrosion/loss and can make classification easy; results are not failure lead-time evidence.
- Saved source-manifest SHA-256 ties a report to local dataset metadata. Raw dataset hashes are in that manifest. Upstream model/notebook artifacts are never loaded.

## Run and inspect

```bash
source /home/praveen/venv-ardupilot/bin/activate
cd /mnt/deepa/IoT/code/oil-gas-monitoring
python -m scripts.train_modules
# Or select one or more modules:
python -m scripts.train_modules --module well-facies --module ppe-images
```

Results: `artifacts/<module-id>/report.json`. Local artifacts include preprocessing+ML bundles and PyTorch state dictionaries generated by this project. Never load untrusted joblib/pickle files. Artifacts are excluded from source control and are not copied into the basic API Docker image.

The **Model workbench** UI lists every module and actual run status. Select View report to inspect held-out metrics, split, features and limitations. NLP search returns source excerpts. These endpoints require the reviewer credential. Training is intentionally an offline CLI operation; browser requests cannot start arbitrary compute jobs.

API: `GET /v1/modules`, `GET /v1/modules/{id}/report`, `GET /v1/knowledge/search?q=...`. A module without a report is `not_run`. A deployment without optional analytics dependencies returns 503 for knowledge search. Docker deployments must explicitly supply approved model/report artifacts and analytics dependencies before enabling them.

## Before operational use

Improve on the reference baselines with a defined site task; run cross-validation, proper temporal backtests and site-held-out evaluation; review class imbalance, uncertainty and leakage; establish approved thresholds and monitoring. PPE detection needs a trained and reviewed object detector with person association and task/zone rules. NLP generation needs an explicitly selected language model, source access controls and grounded-answer evaluation. These are open requirements; the current transformer is not a domain language model.

## Observed baseline quality

See [actual results](model-results.md). The PPE CNN achieved balanced accuracy 0.476 and the small ViT 0.500 against a majority reference of 0.500. These baselines have not demonstrated useful detection performance. Pipeline condition results near 0.99 describe contemporaneous condition classification and may reflect derived-feature leakage; they are not evidence of predictive maintenance readiness. No model was promoted to live operation.
